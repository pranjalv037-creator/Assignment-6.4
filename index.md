Assignment 6.4 — Positioning Practice

Aim

To create a webpage demonstrating CSS positioning properties, including sticky navigation, a fixed floating button, an absolute badge, relative positioning, and z-index.

CSS Positioning Properties

1. Position: Sticky — Keeps the navigation bar at the top while scrolling within its scrolling container.
2. Position: Fixed — Keeps the Help button at a fixed position on the screen.
3. Position: Absolute — Places the badge at a specific position inside its positioned parent.
4. Position: Relative — Establishes the card as the positioning reference for the badge.
5. Z-index — Controls the stacking order of overlapping elements.

Implementation

- A sticky navigation bar links to different webpage sections.
- Four sections provide enough content to demonstrate scrolling.
- A floating Help button remains at the bottom-right corner.
- A NEW badge is positioned inside the featured card.
- Z-index values ensure that the navigation bar, badge, and floating button appear above surrounding content where required.

Files Included

- "index.html" — HTML structure of the webpage.
- "style.css" — CSS positioning and layout styles.
- "positioning-screenshot.png" — Screenshot showing the sticky navigation bar, floating Help button, and positioned badge.
